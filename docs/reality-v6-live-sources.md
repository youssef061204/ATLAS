The [actual native worker](../scripts/process_caltrans_live_v6.py) accepts only the reviewed HTTPS Caltrans host, keeps TLS verification, checks live HLS sequence/segment structure, rejects JPEG/VOD/encrypted inputs, bounds downloads to 8 MB and buffers to 60 seconds, resets tracker identities after discontinuities/gaps, and reports stale sequence/rolling visible-track telemetry. It decodes every frame and performs 320-pixel COCO YOLO11n/ByteTrack inference on every sixth frame to keep up on CPU. A blank initialization is excluded from source counts. A heavier first configuration exceeded the buffer deadline and correctly failed; it is not included as a successful trial. Temporary files are removed in `finally` and the private directory is deleted on exit. Tests cover source restrictions, snapshot rejection, bounded segments, sequence duplication, discontinuities and stale/expired rolling state. Actual reconnect reliability through extended provider outages remains unverified.

[Recorded telemetry and provenance](../artifacts/reality/v6/live-ingestion-results.json) is an archived execution record, **not current live metrics**. No images/segments are published. Source update age is pipeline telemetry, not absolute camera-to-display latency; HLS program wall-clock timestamps are unavailable. The zero nighttime predictions cannot establish detection/tracking quality, traffic-count accuracy, physical speeds, queues or live SUMO fidelity. Those require calibrated observations and further successful experiments. The official nearby southbound Blue Bird manifest returned 404; other reviewed northbound/Broadway manifests returned 200. The worker never replaces an unavailable HLS feed with the camera's JPEG poster.

Run `python scripts/process_caltrans_live_v6.py --seconds 60` locally to repeat a bounded trial, subject to current source availability and terms. Rolling JSON printed **during execution** is labelled live processing; the public app only displays the dated archived summary. No free host has been configured for persistent native live inference.
