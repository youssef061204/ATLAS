# Actual ATLAS 3.0 presentation capture

Four 1440×900 application screenshots and a 38-second 1280×800 H.264 walkthrough were captured from the production-mode public application using `frontend/scripts/capture-city-media.mjs`. The source WebM remains in ignored local working data; the published MP4 is approximately 1.6 MB and supports progressive playback.

The CV image uses the original attributed Mixkit real-video replay. Its separate aerial-profile sampled FPS is not the UA-DETRAC complete-pipeline benchmark. The comparison follows actual Toronto experiment `c3167deb29f86113d5245f2e`; all positions and benchmark values are produced by the application. Its sparse conditional demand and simulated delay differences are not calibrated city savings. The graph laboratory is a separate highway-domain evaluation.

No official city camera image is retained or redistributed. Camera/source maps use catalog coordinates and attributed OpenStreetMap geometry. `provenance.json` records the capture time and routes. No screenshot or benchmark number was manually altered.
