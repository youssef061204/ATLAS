# Authentic presentation media

Four optimized WebP images show the actual running ATLAS public-demo build: synchronized CV/digital twin, analytics, controlled signal comparison, and real benchmark dashboard. `frontend/scripts/capture-portfolio.mjs` captures eight source views; PNG originals are ignored. WebP compression/resizing changes presentation only, never displayed values.

`demo.mp4` is a 58.8-second actual browser walkthrough, encoded as H.264 with fast-start metadata and no audio, approximately 2.8 MB. It includes actual CV replay, heatmap, analytical/safety/forecast screens, controlled optimization, and the separate real benchmarks including negative control results. The recording runs at 1.08x speed for a concise presentation; no results are edited. The complete original WebM is in `../demo/atlas-walkthrough.webm`.

The publicly replayed annotated traffic video is an integrated ATLAS presentation derived from Mixkit #1755 under its Stock Video Free License. The original stock clip and raw UA-DETRAC/METR-LA/RESCO datasets are not redistributed. `../demo/presentation-manifest.json` records the annotated video's and actual simulation output's checksums and scope.
