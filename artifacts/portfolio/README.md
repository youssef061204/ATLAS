# Genuine application presentation media

Four optimized WebP images show the actual running public-demo build: synchronized CV/digital twin, analytics, the improved RESCO MPC comparison, and the four-controller benchmark with confidence intervals and failed transfer visible. PNG originals are ignored. `frontend/scripts/capture-portfolio.mjs --signal-only` refreshes the two controller views; WebP compression changes presentation only, never displayed values.

`demo.mp4` is a 58.2-second actual browser walkthrough, H.264 with fast-start metadata and no audio, approximately 3 MB. It shows real CV replay/heatmap, analytics, safety and forecasting, actual precomputed SUMO queues from final seed 5001, the improved benchmark, and the historical poor result. The original 62.9-second browser recording is in `../demo/atlas-walkthrough.webm`; playback is encoded at 1.08x for a concise presentation. No benchmark values or screenshots are altered.

The public site clearly distinguishes precomputed replay from local live processing. RESCO outcomes are real-world-derived simulated interventions, not field validation. The four portfolio files and walkthrough are copied byte-for-byte into the existing YoussefElsokkary repository.
